Section 1 · Visual foundations

The same tokens and components, shown in light ("paper notebook") and dark ("night notebook"). Every screen will be built only from these. Notes on the decisions are below the boards.

Decisions behind it

  • Fonts: Fraunces (headings), Inter (all UI and body) and Space Grotesk (numbers only: countdowns, ranks, scores, fit %). All are open-licensed (OFL) and self-hosted as woff2 in assets/fonts/, so there's still no CDN. Space Grotesk is subset to digits and a few symbols, so it's tiny.
  • One accent: coral. Small coral text uses a darker shade (--accent-text) so it passes WCAG AA contrast on paper. The highlighter underline is used only in display headlines.
  • The notebook signature: 1.5px ink outlines with a 3px hard offset shadow, used on cards and secondary buttons only. Inputs and chips get soft outlines so forms stay calm.
  • RIASEC colours: six fixed pastels, each always paired with its letter so colour is never the only signal. The same colours are used everywhere a dimension appears (results, matches, explore, career detail).
  • Fit levels use status colours (green / amber / grey) instead of today's 6-step ramp.
  • Dark mode: the same token names with charcoal paper and cream ink. Shadows go true black, the coral gets lighter, and the contest card flips to cream so it still pops.
